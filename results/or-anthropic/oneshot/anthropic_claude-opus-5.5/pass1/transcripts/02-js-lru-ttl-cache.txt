# cache.mjs

```js
// cache.mjs
// LRU cache with per-entry TTL. Uses an injected clock (`now`) for all time math.

function validateTtl(ttl, name) {
  if (typeof ttl !== 'number' || Number.isNaN(ttl)) {
    throw new TypeError(`${name} must be a number (got ${String(ttl)})`);
  }
}

export class LruTtlCache {
  #capacity;
  #defaultTtlMs;
  #now;
  // Map keeps insertion order: first entry = least recently used,
  // last entry = most recently used.
  #map = new Map(); // key -> { value, expiresAt }

  constructor({ capacity, defaultTtlMs = Infinity, now = () => Date.now() } = {}) {
    if (!Number.isInteger(capacity) || capacity < 1) {
      throw new RangeError(`capacity must be an integer >= 1 (got ${String(capacity)})`);
    }
    validateTtl(defaultTtlMs, 'defaultTtlMs');
    if (typeof now !== 'function') {
      throw new TypeError('now must be a function returning milliseconds');
    }
    this.#capacity = capacity;
    this.#defaultTtlMs = defaultTtlMs;
    this.#now = now;
  }

  // An entry is expired when now >= expiresAt; Infinity never expires.
  static #isExpired(entry, t) {
    return entry.expiresAt !== Infinity && t >= entry.expiresAt;
  }

  #purgeExpired(t) {
    for (const [key, entry] of this.#map) {
      if (LruTtlCache.#isExpired(entry, t)) this.#map.delete(key);
    }
  }

  set(key, value, ttlMs) {
    const ttl = ttlMs ?? this.#defaultTtlMs;
    validateTtl(ttl, 'ttlMs');
    const t = this.#now();
    const expiresAt = ttl === Infinity ? Infinity : t + ttl;

    // Remove any existing entry so re-insertion moves it to MRU position.
    this.#map.delete(key);

    // An entry that is already expired on arrival (ttl <= 0) would be
    // invisible to every read; storing it could only evict live entries.
    if (expiresAt !== Infinity && t >= expiresAt) return this;

    if (this.#map.size >= this.#capacity) {
      this.#purgeExpired(t);
      while (this.#map.size >= this.#capacity) {
        // Evict least recently used (first in insertion order).
        const lruKey = this.#map.keys().next().value;
        this.#map.delete(lruKey);
      }
    }

    this.#map.set(key, { value, expiresAt });
    return this;
  }

  get(key) {
    const entry = this.#map.get(key);
    if (entry === undefined) return undefined;
    if (LruTtlCache.#isExpired(entry, this.#now())) {
      this.#map.delete(key);
      return undefined;
    }
    // Refresh recency.
    this.#map.delete(key);
    this.#map.set(key, entry);
    return entry.value;
  }

  has(key) {
    const entry = this.#map.get(key);
    if (entry === undefined) return false;
    if (LruTtlCache.#isExpired(entry, this.#now())) {
      this.#map.delete(key);
      return false;
    }
    return true;
  }

  delete(key) {
    return this.#map.delete(key);
  }

  get size() {
    this.#purgeExpired(this.#now());
    return this.#map.size;
  }

  keys() {
    this.#purgeExpired(this.#now());
    return Array.from(this.#map.keys()).reverse(); // MRU -> LRU
  }
}
```

**Design notes:**

- **Recency.** A `Map` stores the entries in insertion order. Touching an entry deletes it and re-inserts it, which moves it to the end. So the first key is the LRU entry and the last key is the MRU entry. This keeps `get`, `set`, `has` and `delete` O(1).
- **Eviction.** Eviction only runs when a new key would push the cache past capacity:
  1. Expired entries are purged first.
  2. If the cache is still full, the first (LRU) key is dropped.
- **Clock use.**
  - Every operation reads `now()` exactly once, so each operation sees a consistent time.
  - `Date.now()` appears only as the default value of the `now` option. It is never called directly.
- **Expiry rules.**
  - An entry is expired when `now() >= expiresAt`.
  - A TTL of `Infinity` gives `expiresAt = Infinity`, which never expires.
  - A TTL of zero or less gives an expiry at or before now, so the entry is expired immediately.
- **Already-expired `set`.** Such an entry is not stored, and any previous value for that key is removed. Every read would treat it as absent anyway. Storing it could wrongly evict a live entry from a full cache.
- **Validation.**
  - `capacity` must be an integer of at least 1; otherwise a `RangeError` is thrown. This rejects `Infinity`, non-integers and a missing option.
  - If a TTL is `NaN` or not a number, a `TypeError` is thrown. This choice goes beyond the spec: a `NaN` expiry would silently never expire.
