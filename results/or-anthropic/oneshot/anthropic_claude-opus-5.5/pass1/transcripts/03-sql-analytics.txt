Each file below holds one `SELECT`. After the files are a few notes on edge cases.

**q1.sql**
```sql
SELECT
  c.name AS customer_name,
  ROUND(COALESCE(SUM(oi.quantity * p.unit_price), 0.0), 2) AS revenue
FROM customers c
JOIN orders o
  ON o.customer_id = c.id
 AND o.status = 'completed'
LEFT JOIN order_items oi
  ON oi.order_id = o.id
LEFT JOIN products p
  ON p.id = oi.product_id
GROUP BY c.id, c.name
ORDER BY revenue DESC, customer_name ASC;
```

**q2.sql**
```sql
SELECT
  p.name AS product_name,
  SUM(oi.quantity) AS units_sold
FROM products p
JOIN order_items oi
  ON oi.product_id = p.id
JOIN orders o
  ON o.id = oi.order_id
 AND o.status = 'completed'
GROUP BY p.id, p.name
HAVING SUM(oi.quantity) > 0
ORDER BY units_sold DESC, product_name ASC
LIMIT 3;
```

**q3.sql**
```sql
SELECT
  c.name AS customer_name,
  c.country AS country
FROM customers c
WHERE NOT EXISTS (
  SELECT 1 FROM orders o WHERE o.customer_id = c.id
)
ORDER BY customer_name ASC;
```

**q4.sql**
```sql
SELECT
  strftime('%Y-%m', o.ordered_at) AS month,
  ROUND(SUM(oi.quantity * p.unit_price), 2) AS revenue
FROM orders o
JOIN order_items oi
  ON oi.order_id = o.id
JOIN products p
  ON p.id = oi.product_id
WHERE o.status = 'completed'
  AND strftime('%Y', o.ordered_at) = '2025'
GROUP BY month
HAVING SUM(oi.quantity * p.unit_price) > 0
ORDER BY month ASC;
```

**Notes on edge cases**

- **Duplicate names:** q1 and q2 group by `id` as well as name. Two different customers or products with the same name stay as separate rows.
- **Completed orders with no items:** in q1, a customer can have a completed order with no line items. That customer still appears, with revenue `0.0`. The joins to items and products are `LEFT JOIN`s, and `COALESCE` turns the empty sum into zero.
- **No completed sales:** q2 uses inner joins, so only products with completed-order lines appear. `HAVING SUM > 0` also drops products whose only lines have zero quantity.
- **Customers with no orders:** q3 uses `NOT EXISTS`. This avoids the NULL pitfalls of `NOT IN`.
- **Time parts in dates:** q4 uses `strftime`. It works whether `ordered_at` is a plain date or an ISO datetime.
- **Zero-revenue months:** q4 leaves out months with zero revenue.
