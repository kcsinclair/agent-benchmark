Each file below contains one `SELECT` statement. All queries group by `id` as well as name, so two customers or products with the same name stay separate.

**q1.sql**
```sql
SELECT c.name AS customer_name,
       ROUND(COALESCE(SUM(oi.quantity * p.unit_price), 0.0), 2) AS revenue
FROM customers c
JOIN orders o
  ON o.customer_id = c.id
 AND o.status = 'completed'
LEFT JOIN order_items oi
  ON oi.order_id = o.id
LEFT JOIN products p
  ON p.id = oi.product_id
GROUP BY c.id, c.name
ORDER BY revenue DESC, customer_name ASC;
```

**q2.sql**
```sql
SELECT p.name AS product_name,
       SUM(oi.quantity) AS units_sold
FROM products p
JOIN order_items oi
  ON oi.product_id = p.id
JOIN orders o
  ON o.id = oi.order_id
 AND o.status = 'completed'
GROUP BY p.id, p.name
HAVING SUM(oi.quantity) > 0
ORDER BY units_sold DESC, product_name ASC
LIMIT 3;
```

**q3.sql**
```sql
SELECT c.name AS customer_name,
       c.country AS country
FROM customers c
WHERE NOT EXISTS (
  SELECT 1 FROM orders o WHERE o.customer_id = c.id
)
ORDER BY customer_name ASC;
```

**q4.sql**
```sql
SELECT strftime('%Y-%m', o.ordered_at) AS month,
       ROUND(SUM(oi.quantity * p.unit_price), 2) AS revenue
FROM orders o
JOIN order_items oi
  ON oi.order_id = o.id
JOIN products p
  ON p.id = oi.product_id
WHERE o.status = 'completed'
  AND strftime('%Y', o.ordered_at) = '2025'
GROUP BY month
HAVING SUM(oi.quantity * p.unit_price) <> 0
ORDER BY month ASC;
```

Choices on edge cases:
- **q1:** A customer whose completed orders have no line items still appears, with revenue `0.0`. That customer does have a completed order, so the rules require a row. The `LEFT JOIN`s and `COALESCE` handle this.
- **q2:** A product counts as sold only if its total completed quantity is above zero. So a product whose only completed lines have quantity 0 is left out.
