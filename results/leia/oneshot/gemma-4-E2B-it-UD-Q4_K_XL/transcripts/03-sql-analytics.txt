Here are the four SQL files as requested.

### `q1.sql` — Revenue per customer

```sql
SELECT
  T1.name,
  ROUND(SUM(T3.quantity * T2.unit_price), 2)
FROM customers AS T1
INNER JOIN orders AS T4
  ON T1.id = T4.customer_id
INNER JOIN order_items AS T3
  ON T4.id = T3.order_id
INNER JOIN products AS T2
  ON T3.product_id = T2.id
WHERE
  T4.status = 'completed'
GROUP BY
  T1.id
ORDER BY
  revenue DESC,
  T1.name ASC;
```

### `q2.sql` — Top 3 products by units sold

```sql
SELECT
  T2.name,
  SUM(T3.quantity) AS units_sold
FROM orders AS T1
INNER JOIN order_items AS T3
  ON T1.id = T3.order_id
INNER JOIN products AS T2
  ON T3.product_id = T2.id
WHERE
  T1.status = 'completed'
GROUP BY
  T2.name
ORDER BY
  units_sold DESC,
  T2.name ASC
LIMIT 3;
```

### `q3.sql` — Customers with no orders at all

```sql
SELECT
  T1.name,
  T1.country
FROM customers AS T1
LEFT JOIN orders AS T2
  ON T1.id = T2.customer_id
WHERE
  T2.id IS NULL
ORDER BY
  T1.name ASC;
```

### `q4.sql` — Monthly revenue for 2025

```sql
SELECT
  strftime('%Y-%m', T1.ordered_at) AS month,
  ROUND(SUM(T3.quantity * T2.unit_price), 2) AS revenue
FROM orders AS T1
INNER JOIN order_items AS T3
  ON T1.id = T3.order_id
INNER JOIN products AS T2
  ON T3.product_id = T2.id
WHERE
  T1.status = 'completed' AND STRFTIME('%Y', T1.ordered_at) = '2025'
GROUP BY
  month
HAVING
  SUM(T3.quantity * T2.unit_price) > 0
ORDER BY
  month ASC;
```
