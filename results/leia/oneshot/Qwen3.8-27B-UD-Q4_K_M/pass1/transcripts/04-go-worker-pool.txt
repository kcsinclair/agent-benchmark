The key design: launch exactly `workers` goroutines that pull task indices from a channel. When an error occurs or the parent context is cancelled, a derived context is cancelled, causing workers to stop pulling new tasks. `sync.WaitGroup` ensures we wait for all in-flight tasks.

```go
package main

import (
	"context"
	"errors"
	"sync"
)

// Task is one unit of work.
type Task func(ctx context.Context) (any, error)

// Run executes tasks with at most `workers` running concurrently and returns
// their results in the same order as the input slice.
func Run(ctx context.Context, tasks []Task, workers int) ([]any, error) {
	if workers < 1 {
		return nil, errors.New("workers must be at least 1")
	}
	if len(tasks) == 0 {
		return []any{}, nil
	}

	// Derived context that gets cancelled on first error or parent cancellation.
	taskCtx, cancel := context.WithCancel(ctx)
	defer cancel()

	results := make([]any, len(tasks))
	var firstErr error
	var errOnce sync.Once
	var wg sync.WaitGroup

	// Channel to distribute task indices to workers.
	taskIdx := make(chan int, len(tasks))
	for i := range tasks {
		taskIdx <- i
	}
	close(taskIdx)

	// Launch exactly `workers` goroutines; each pulls indices until the
	// channel is drained or the context is cancelled.
	for w := 0; w < workers; w++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			for idx := range taskIdx {
				// If the context is already cancelled (due to a prior error
				// or parent cancellation), stop pulling new tasks.
				if taskCtx.Err() != nil {
					return
				}

				result, err := tasks[idx](taskCtx)
				if err != nil {
					errOnce.Do(func() {
						firstErr = err
						cancel() // signal all other workers to stop
					})
				} else {
					results[idx] = result
				}
			}
		}()
	}

	wg.Wait()

	if firstErr != nil {
		return nil, firstErr
	}
	if ctx.Err() != nil {
		return nil, ctx.Err()
	}
	return results, nil
}
```

**How it satisfies each requirement:**

1. **Ordering** — `results[idx]` is written by the worker that executes `tasks[idx]`, so `results[i]` always corresponds to `tasks[i]`.

2. **Bounded concurrency** — Exactly `workers` goroutines are spawned, each executing one task at a time. No more than `workers` tasks run concurrently.

3. **Validation** — `workers < 1` returns an error immediately; `len(tasks) == 0` returns an empty slice and nil.

4. **Fail fast** — On the first task error, `errOnce` records it and calls `cancel()`, which cancels `taskCtx`. Workers check `taskCtx.Err()` before starting each new task and return early. Already-running tasks receive the cancelled context (cooperative cancellation). `wg.Wait()` blocks until all started tasks finish — no goroutine leaks.

5. **Context cancellation** — `taskCtx` is derived from the parent `ctx`, so parent cancellation propagates automatically. Workers stop pulling new tasks, and `Run` returns `ctx.Err()`.

6. **No busy-waiting** — Synchronization uses channels, `sync.WaitGroup`, and `sync.Once` only.
