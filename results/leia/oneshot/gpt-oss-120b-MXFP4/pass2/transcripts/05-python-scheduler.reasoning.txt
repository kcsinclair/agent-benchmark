We need to write solution for weighted interval scheduling O(n log n). Need to return total weight and list of original indices sorted by start time (tie by index). Approach: sort jobs by end time (or start?). Classic DP: sort by end time, compute p[i] = last job before i that doesn't overlap (end <= start_i). DP[i] = max(DP[i-1], weight_i + DP[p[i]]). Then reconstruct chosen indices.

We need to output indices sorted by start time (tie by index). After reconstruction we have set of indices; we can sort them by (start, index) before returning.

Complexities: n up to 200k, O(n log n). Use binary search for p[i] using list of end times.

Implementation details:

- Input jobs list of tuples (float, float, float). Keep original index.

- Create list of (end, start, weight, idx). Sort by end ascending, tie maybe by start? Not needed.

- Build arrays: ends = [end_i], starts = [start_i], weights = [weight_i], idxs = [orig_idx].

- Compute p using bisect_right on ends: for each i, find rightmost j < i with ends[j] <= start_i. Use bisect_right(ends, start_i) - 1.

- DP array of length n+1 (dp[0]=0). Use float.

- Also need to reconstruct: we can store decision boolean choose[i] = True if taking job i-1 (since dp index offset). Or we can reconstruct by walking backwards: i = n; while i>0: if dp[i] == dp[i-1]: i -=1 else: select idxs[i-1]; i = p[i-1]+1 (since dp index offset). Need careful.

Implementation:

n = len(jobs)
if n==0: return (0.0, [])

jobs_with_idx = [(s, e, w, i) for i,(s,e,w) in enumerate(jobs)]

sorted_jobs = sorted(jobs_with_idx, key=lambda x: x[1])  # sort by end

starts = [s for s, e, w, i in sorted_jobs]
ends = [e for s, e, w, i in sorted_jobs]
weights = [w for s, e, w, i in sorted_jobs]
orig_idx = [i for s, e, w, i in sorted_jobs]

import bisect

p = [0]*n
for i in range(n):
    # find last job with end <= start_i
    j = bisect.bisect_right(ends, starts[i]) - 1
    p[i] = j  # could be -1 if none

dp = [0.0]*(n+1)
# dp[i] corresponds to first i jobs (sorted by end)
for i in range(1, n+1):
    # job index i-1
    incl = weights[i-1] + (dp[p[i-1]+1] if p[i-1] != -1 else 0.0)
    excl = dp[i-1]
    dp[i] = incl if incl > excl else excl

# reconstruct
chosen = []
i = n
while i > 0:
    if dp[i] == dp[i-1]:
        i -= 1
    else:
        # job i-1 taken
        chosen.append(orig_idx[i-1])
        i = p[i-1] + 1  # move to job before compatible
# chosen currently in reverse order of sorted by end; need to sort by start then index
chosen_set = set(chosen)  # maybe not needed
# Build list sorted by start then index
chosen_sorted = sorted(chosen, key=lambda idx: (jobs[idx][0], idx))

total_weight = dp[n]
return (total_weight, chosen_sorted)

Edge Cases: floating point equality; dp[i] == dp[i-1] may be ambiguous due to floating errors. Since weights are floats, but we can compare with tolerance: if dp[i] - dp[i-1] > 1e-12 then taken else not. Or we can store decision bool.

Better: store decision bool: take[i] = incl > excl. Then reconstruct using that.
