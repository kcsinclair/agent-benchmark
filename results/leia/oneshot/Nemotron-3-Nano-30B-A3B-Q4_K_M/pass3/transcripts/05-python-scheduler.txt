To solve the weighted interval scheduling problem efficiently for large inputs (up to 200,000 jobs), we need an O(n log n) solution that avoids recursion and handles all edge cases correctly. The approach involves sorting jobs by end time, using binary search to find non-overlapping predecessors, and dynamically computing the optimal schedule using iterative dynamic programming.

### Approach
1. **Sort Jobs by End Time**: This allows us to process each job in order and efficiently find the latest job that doesn't overlap with the current job.
2. **Binary Search for Predecessors**: For each job, use binary search to find the last job that ends before or at the start of the current job. This helps in identifying non-overlapping intervals.
3. **Dynamic Programming with Iteration**: Instead of recursion, use an iterative approach to compute the maximum weight achievable up to each job. This avoids recursion depth issues and ensures O(n) time for DP computation.
4. **Reconstructing the Optimal Schedule**: After computing the DP array, backtrack to collect the indices of the jobs included in the optimal schedule. These indices are then sorted by their start times to meet the output requirement.

### Solution Code
```python
import bisect

def best_schedule(jobs):
    if not jobs:
        return (0.0, [])
    
    n = len(jobs)
    sorted_jobs = sorted(enumerate(jobs), key=lambda x: x[1][1])
    starts = [job[1][0] for job in sorted_jobs]
    ends = [job[1][1] for job in sorted_jobs]
    weights = [job[1][2] for job in sorted_jobs]
    
    dp = [0.0] * n
    dp[0] = weights[0]
    
    for i in range(1, n):
        current_start = starts[i]
        pos = bisect.bisect_right(ends, current_start)
        j = pos - 1
        include_weight = weights[i]
        if j >= 0:
            include_weight += dp[j]
        dp[i] = max(dp[i-1], include_weight)
    
    total_weight = dp[-1]
    current = n - 1
    chosen_indices = []
    
    while current >= 0:
        if current == 0:
            if dp[current] == weights[current]:
                chosen_indices.append(sorted_jobs[current][0])
            break
        else:
            if dp[current] == dp[current-1]:
                current -= 1
            else:
                j = bisect.bisect_right(ends, starts[current]) - 1
                if j >= 0:
                    current = j
                else:
                    current = -1
                chosen_indices.append(sorted_jobs[current + 1][0])
    
    chosen_indices.sort(key=lambda idx: starts[idx])
    return (total_weight, chosen_indices)
```

### Explanation
1. **Initial Checks**: If the input list is empty, return `(0.0, [])` immediately.
2. **Sorting Jobs**: Jobs are sorted by their end times to facilitate efficient predecessor searches. Each job is paired with its original index to track positions after sorting.
3. **Dynamic Programming Setup**: 
   - `starts`, `ends`, and `weights` arrays store the respective attributes of each job in sorted order.
   - The `dp` array is initialized to store the maximum weight achievable up to each job.
4. **DP Array Calculation**:
   - For each job, binary search (`bisect_right`) locates the latest non-overlapping job. The weight of including the current job is compared with excluding it to update `dp[i]`.
5. **Backtracking for Optimal Schedule**:
   - Starting from the last job, backtrack through the `dp` array to collect indices of jobs included in the optimal schedule.
   - These indices are sorted by their original start times to meet the output requirement.
6. **Result Compilation**: The total weight (from `dp[-1]`) and the sorted list of chosen indices are returned as the result.

This approach efficiently handles large inputs by leveraging sorting, binary search, and iterative DP, ensuring optimal performance and correctness for all valid inputs.
