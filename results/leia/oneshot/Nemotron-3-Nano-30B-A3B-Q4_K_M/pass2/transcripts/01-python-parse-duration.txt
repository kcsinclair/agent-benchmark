To solve this problem, we need to parse a human-readable duration string into its total equivalent in seconds as a floating-point number. The solution involves validating the input string according to specific rules and then converting each component of the duration into seconds.

### Approach
1. **Input Validation**: 
   - Check if the input is a string; if not, raise a `TypeError`.
   - Strip leading and trailing whitespace from the input string.
   - Ensure the stripped string is non-empty; otherwise, raise a `ValueError`.

2. **Sign Handling**:
   - Check for an optional leading minus sign (`-`). If present, set a negative flag and process the remaining string.

3. **Tokenization**:
   - Split the processed string into tokens where each token starts with a digit followed by a unit (`h`, `m`, `s`, `ms`).
   - Validate each token to ensure it starts with a digit and ends with a valid unit. The number part must be a valid non-negative decimal (e.g., `1.5` is valid, but `.5` or `5.` is invalid).

4. **Order and Uniqueness Check**:
   - Ensure the units in the tokens are in strictly descending order of size (`h` > `m` > `s` > `ms`) and each unit appears at most once.

5. **Conversion to Seconds**:
   - Convert each component into seconds based on its unit:
     - Hours (`h`): multiply by 3600.
     - Minutes (`m`): multiply by 60.
     - Seconds (`s`): use as-is.
     - Milliseconds (`ms`): divide by 1000.
   - Sum all components, applying the negative sign if applicable.

### Solution Code
```python
def parse_duration(text: str) -> float:
    if not isinstance(text, str):
        raise TypeError("Input must be a string")
    
    s = text.strip()
    if not s:
        raise ValueError("Empty string")
    
    sign = 1
    if s[0] == '-':
        sign = -1
        s = s[1:]
        if not s:
            raise ValueError("Invalid format after minus sign")
    
    tokens = []
    i = 0
    n = len(s)
    while i < n:
        if not s[i].isdigit():
            raise ValueError("Invalid token: expected digit at start")
        j = i
        while j < n and s[j].isdigit():
            j += 1
        if j >= n:
            raise ValueError("Number not followed by unit")
        num_str = s[i:j]
        if '.' in num_str:
            parts = num_str.split('.')
            if len(parts) != 2:
                raise ValueError("Invalid number format")
            if parts[0] == '' or parts[1] == '':
                raise ValueError("Invalid number format")
        unit_str = s[j:j+2]
        if unit_str not in ['h', 'm', 's', 'ms']:
            raise ValueError("Invalid unit")
        unit = unit_str[0]
        tokens.append((unit, num_str))
        i = j + len(unit_str)
    
    if not tokens:
        raise ValueError("No components found")
    
    units = [unit for unit, _ in tokens]
    if len(units) != len(set(units)):
        raise ValueError("Duplicate units")
    
    order_map = {'h': 0, 'm': 1, 's': 2, 'ms': 3}
    for idx in range(1, len(units)):
        if order_map[units[idx-1]] >= order_map[units[idx]]:
            raise ValueError("Units not in descending order")
    
    total_seconds = 0.0
    for unit, num_str in tokens:
        if unit == 'h':
            multiplier = 3600.0
        elif unit == 'm':
            multiplier = 60.0
        elif unit == 's':
            multiplier = 1.0
        else:  # 'ms'
            multiplier = 1.0 / 1000.0
        num_val = float(num_str)
        total_seconds += num_val * multiplier
    
    return sign * total_seconds
```

### Explanation
1. **Input Validation**: The function first checks if the input is a string. If not, it raises a `TypeError`. It then strips any leading or trailing whitespace and checks if the resulting string is empty, raising a `ValueError` if it is.
2. **Sign Handling**: If the string starts with a minus sign, the function processes the remaining string and sets a negative flag.
3. **Tokenization**: The string is split into tokens where each token consists of a number followed by a unit. Each token is validated to ensure the number part is a valid non-negative decimal and the unit is one of `h`, `m`, `s`, or `ms`.
4. **Order and Uniqueness Check**: The units in the tokens must be in strictly descending order (e.g., `h` before `m` before `s` before `ms`) and each unit must appear only once. If not, a `ValueError` is raised.
5. **Conversion to Seconds**: Each component is converted to seconds based on its unit. The components are summed, and the result is adjusted by the sign (if the input started with a minus sign). The final result is returned as a floating-point number representing the total duration in seconds.

This approach ensures that all specified rules are adhered to, and any invalid input raises the appropriate exception, providing a robust and reliable solution for parsing duration strings.
